### 🐡 Блок 1, Вариант 2. Простые запросы с фильтрацией 
Найдите все рейсы прибившие в SVO в интервале с 16:00 до 19:00 2017-07-22
```sql
SELECT * FROM flights 
WHERE arrival_airport = 'SVO' 
AND actual_arrival >= TIMESTAMP '2017-07-22 16:00:00' 
AND actual_arrival <= TIMESTAMP '2017-07-22 19:00:00';
```
**Пояснение** 

`SELECT * FROM flights` - Выбор всех атрибутов(столбцов) из таблицы flights

`WHERE (...) AND (...)` - фильтрация, т. е. выбор только тех строк, в которых выполняются заданные условия. В данном случае строка должна удовлетворить трём условиям, чтобы попасть в ответ запроса

### 🐡 Блок 2, Вариант 2. Обновление данных
Увеличьте стоимость всех билетов бизнес-класса, которые дешевле чем 10000, на 10%.
```sql
UPDATE ticket_flights
SET amount = amount * 1.1
WHERE fare_conditions LIKE '%Business%'
AND amount < NUMERIC(10, 2) '10000.00';
```
**Пояснение**

`UPDATE table` - изменение таблицы table

`column LIKE '%text%'` - условие, проверяющее, есть ли в атрибуте column строка text (символы '%' означают, что до и после искомой строки могут быть другие символы, а могут и не быть)

`SET column = expression` - заменяет атрибут у всех выбранных строк на выражение expression(может быть как статичным(число, строка), так и зависящим от других столбцов, например, как в запросе из примера)

`NUMERIC(10, 2) '10000.00'` - приводит строку '10000.00' к типу NUMERIC с точностью до двух знаков после запятой(10 означает общее количество цифр)


### 🐡 Блок 3, Вариант 4. Запросы с группировкой
Для каждой даты в июнях найдите колличество рейсов со статусом 'Delayed'
```sql
SELECT scheduled_departure::date, COUNT(*) FROM flights
WHERE EXTRACT(MONTH FROM scheduled_departure) = 8
AND status = 'Delayed'
GROUP BY scheduled_departure::date;
```
**Пояснение**

`scheduled_departure::date` - выбор столбца типа TIMESTAMP, из которого извлечена дата, т. е. возвращаемый тип будет DATE

`COUNT(*)` - _агрегатная функция_, то есть функция, которая обрабатывает сразу несколько строк и аккумулирует какую-то информацию о них. В данном случае - считает кол-во строк, попавших под условие

`EXTRACT(type FROM column)` - функция, позволяющая достать определённую часть даты - год, месяц, день, час, минута, секунда. В конкретном примере нужен был месяц, поэтому "извлекал" MONTH

`GROUP BY column` - группировка по аттрибуту, то есть объединение строк, которые совпадают по атрибуту column, в одну строку
